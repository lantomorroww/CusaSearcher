# CusaSearcher

Приложение для поиска игр PlayStation по названию, коду диска (CUSA/PPSA) и синонимам, с информацией о локализации.

## Возможности
- Поиск по названию, коду, синонимам
- Отображение регионов и кодов дисков
- Информация о локализации (озвучка/субтитры)
- Добавление новых игр
- Тёмная тема, фоновый GIF, музыка с регулировкой громкости

## Стек
C++17, Qt (Widgets, Multimedia), nlohmann/json, CMake.

## Сборка
```bash
cmake -B build
cmake --build build
./build/CusaSearcher
